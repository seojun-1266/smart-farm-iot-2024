## 바닥 아두이노 (`firmware/floor`)

| 핀 | v1 (2024-06) | v2 (2024-08) |
|---|---|---|
| D2 · D3 | 키패드 COL2 · COL1 | 키패드 ROW4 · ROW3 |
| D4 · D5 | 키패드 ROW2 · ROW1 | 키패드 ROW2 · ROW1 |
| D6 | DHT11 DATA | DHT11 DATA |
| D7 | 가습기 모듈 | 가습기 모듈 |
| D8 | LED | LED |
| D9 | HC-06 TXD → (SoftwareSerial RX) | 동일 |
| D10 | HC-06 RXD ← (SoftwareSerial TX) | 동일 |
| D11 | DC 팬 | DC 팬 |
| D12 | 서보 (출입문) | 서보 (출입문) |
| D13 | 부저 | 부저 |
| A0 | 토양 수분 센서 | 토양 수분 센서 ⚠️ + 키패드 COL4 |
| A1 | 조도 센서 | 조도 센서 ⚠️ + 키패드 COL3 |
| A2 | 불꽃 감지 센서 | 불꽃 감지 센서 ⚠️ + 키패드 COL2 |
| A3 | — | 키패드 COL1 |

⚠️ v2는 4x4 키패드의 열을 A0~A3에 연결해 아날로그 센서 핀과 겹칩니다.
같은 핀을 동시에 쓸 수 없으므로, 다시 만든다면 I2C 키패드 모듈이나 아날로그 핀이 많은 보드(Mega)를 쓰는 것이 맞습니다.
